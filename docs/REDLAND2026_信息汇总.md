## 1. 活动基本信息

- **活动名称**：小红书 RED LAND 2026 开放世界冒险岛（官方也写作 REDLAND / RED LAND2.0；第二届，去年为 1.0）
- **Slogan**：欢迎回家 · 永远的主角
- **时间**：2026 年 10 月 2 日 — 10 月 6 日（国庆，共 5 天）
- **地点**：上海市杨浦区复兴岛；场馆名「复兴岛船台 PARK」，地址共青路 130 号（复兴岛地铁站 2 号口步行约 110 米）
- **主办**：小红书
- **规模**：官方口径 100+ 游戏 / 动漫 IP（较去年翻倍），探索区域 10 万平方米以上
- **三大区域**（新闻稿口径）：翻身时空港、重生试炼场、黄金海岸线；官方页面中另有「港口」新地图、「冒险者营地」、「冒险者大道」（巡游路线）等地点名
- **核心概念**：延续「开放世界冒险岛」设定，玩家 = 「主角」，工作人员 / 角色 = 「岛民」「NPC」，主办方吉祥物「薯队长」，用「存档」「读档」「开图」等游戏术语包装整场活动
- **今年新增**：花车巡游（首次）、冒险者营地日光 / 月光双舞台、日夜漫展模式（夜场限定玩法 / 特殊互动 / NPC 夜间专属内容）、港口新区域、不少参展游戏制作人到展台

> 资料来源：主会场 KV（assets/main_venue/01）、大麦场馆信息、中国新闻周刊 2026-08-13、新浪科技 2026-08-12、pchome 2026-08-12。

## 3. 主线玩法与彩蛋玩法（官方「冒险者攻略」半层）

标题：〔冒险者攻略〕— 收集 PIN 形态的存档碎片，解锁完整岛屿地图！

### 3.1 主线玩法

- 自由探索冒险岛，完成各 IP 展位的任务获得 PIN 形式的「存档碎片」，提升存档进度。
- 每个区域打卡对应数量的展位，即可完成该区域「开图」。前往三大区域结算点，兑换对应区域的「冒险岛的信物」。
  - 翻身时空港需打卡 4 个 IP；黄金海岸线、重生试炼场各需打卡 2 个 IP。
- 集齐三个区域的信物，即可合成「RED LAND 2026 冒险岛」冰箱贴（配图：4 枚软盘造型信物 + 岛屿地图造型冰箱贴）。
- 小贴士：夜间模式下将有神秘变体 PIN 掉落，主角们请务必逗留到夜幕降临。
- 展位 PIN 每日掉落数量有限，先到先得。

### 3.2 彩蛋玩法

- **老玩家专属款** PIN「初代目回归」：曾在烈日炎炎下探险的勇士们，你的汗水已经结晶成永恒的纪念，老玩家专属 PIN 等你来领。1.0 登岛老玩家每人限量领取一个。
- **NPC 互动款** PIN（示例图案：「AAA农产品批发」「十抽…」等）：一年一度的限定相遇，岛民们正在期待着主角的到来，积极与岛上 NPC 互动，可能会掉落神秘奖励。只由部分 NPC 角色发放，数量有限、先到先得。

### 3.3 攻略项目可直接用的规则要点

- 收集目标层级：展位 PIN（存档碎片）→ 区域「冒险者拼图」×3（8 月攻略半层称「冒险岛的信物 / 冰箱贴」，同一物）→ 冒险岛拼图完整体；另有夜间 PIN、老玩家 PIN、NPC PIN 三类彩蛋。详见第 13.1 节。
- 区域与打卡数：翻身时空港 4、黄金海岸线 2、重生试炼场 2。**区域映射已确认（9 月 9 日）**：A 区 = 翻身时空港（三丽鸥 A-21、皮乐火影 A-22 官方笔记写明），B 区 = 黄金海岸线（RED LAND 官方号写宝藏码头 B16 在黄金海岸线），C 区 = 重生试炼场（排除法）。PIN 颜色亦印证：A 区展台 PIN 为橙色、B 区为黄色，与官方分区分色一致。
- 每个展位条目右侧有统一黄底 ★ 标记，页面未解释含义（推测为「可获 PIN / 可打卡」标识，需现场确认）。

### 13.4 从这批笔记得到的结论与规律

- 展台详情几乎都发布在**各 IP 自己的官方账号**，标题多为「RED LAND2026 | XX展台活动详情」或「XX REDLAND」，正文常写明展位号与所在区域，图片才是活动 / 任务 / 奖励的主要载体。
- 常见玩法模板：领卡 / 护照 / 工牌 → 打卡若干点位盖章 → 凭卡兑换 PIN 或周边；奖励普遍「每日限量、先到先得」，部分分白天款 / 夜间款（17:30 分界）。
- 夜间分界普遍在 17:30（宝可梦谜拟丘印章、三丽鸥补给站、花车巡游、夜间 PIN），可作为攻略里「夜场」起点的参考，官方仍未给出月下模式的准确时刻。
- 大厂多 IP 展位（阅文）不发笔记而做 **ditto 专题页**（目录页 + 每个 IP 一个子页 + 关注组件），结构与官方主会场一致，`window.__SETUP_SERVER_STATE__` 里能拿到全部图片与子页 id，用 `scripts/fetch-ditto.mjs --sub` 一次抓全。
